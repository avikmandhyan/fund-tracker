# NSE Fund Tracker

A fund portfolio valuation tracker using official NSE bhavcopy data.

## Deploy to Railway

1. Push this folder to a GitHub repo
2. Go to railway.app → New Project → Deploy from GitHub
3. Select the repo → Deploy
4. Your tracker is live at the Railway URL

## Local development

```bash
pip install -r requirements.txt
python server.py
```

Open http://localhost:7001
